# Rapid Prototyping Workflow

1. Definir o problema.
2. Identificar a funcionalidade principal.
3. Definir entrada e saída.
4. Escolher a arquitetura mais simples.
5. Implementar a funcionalidade principal.
6. Testar com dados reais.
7. Corrigir erros.
8. Preparar demonstração.

Priorizar funcionamento sobre quantidade
de funcionalidades.

Evitar abstrações desnecessárias.

Não simular resultados como se fossem reais.
