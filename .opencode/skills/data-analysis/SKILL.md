# Data Analysis Workflow

1. Identificar a origem dos dados.
2. Examinar formato e estrutura.
3. Verificar qualidade e consistência.
4. Identificar valores ausentes.
5. Documentar transformações.
6. Executar análises.
7. Gerar visualizações.
8. Interpretar resultados.

Utilizar Python quando apropriado.

Preservar os dados originais.

Registrar limitações e possíveis vieses.
