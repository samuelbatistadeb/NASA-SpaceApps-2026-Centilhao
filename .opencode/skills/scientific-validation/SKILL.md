# Scientific Validation Workflow

1. Identificar a hipótese testada.
2. Identificar os dados utilizados.
3. Verificar a metodologia.
4. Reproduzir os cálculos quando possível.
5. Comparar resultados com referências.
6. Identificar limitações.
7. Verificar se as conclusões são sustentadas.
8. Documentar evidências.

Nunca afirmar precisão, desempenho ou impacto
sem uma medição que sustente a afirmação.
